This is probably one of the most asked questions I get when I meet the community during conferences or training: "What is the process of upgrading ERPNext/Frappe instance from vX to vY?"

This time, I decided to create a comprehensive guide which you can use as a reference to get a major version upgrade done for your Frappe/ERPNext instance.

The playbook **contains the exact process** that I would use to upgrade ERPNext from v15 to v16. But the core processes remains the same for any upgrade, e.g. v14 to v15.

### Concrete Example

I have used a realistic example with multiple custom apps and 17 months of data! We will debug and resolve the issues together.

I have not assumed you can use [Frappe Cloud](https://frappe.io/cloud) so that you use this playbook even if you are self-hosting.
